# Privacy and Source

## What this repository is

A portfolio showcase for a production application. It describes the engineering of 2D Turbo Racing; it is not a source distribution.

## What is published

- Written descriptions of architecture, design decisions and trade-offs
- Original diagrams created for this showcase
- Real screenshots from the Mobile build, captured with a guest account
- The app icon and the Android TV launcher banner artwork, resized

## What is intentionally not published

- Production source code, in whole or in part
- Tuning values, spawn rates, reward tables, pricing and economy data
- Build and signing configuration, certificates and keystores
- Firebase and Google service configuration, API keys and tokens
- Ad network identifiers, placement IDs and account details
- Billing product IDs and store listing identifiers
- Internal endpoints, database paths and security-rule contents
- Version control history of the production repositories
- User data of any kind

## How the descriptions were produced

The production projects were inspected read-only. Statements in this repository describe behaviour observed in code, manifests or project documents; where behaviour could not be confirmed it is worded conservatively or left out. Diagram labels are conceptual and do not correspond to production identifiers.

## Images

- **Screenshots** are real captures from the Mobile build. They show a guest profile and generated alias; no account details, notifications, debug overlays or ad identifiers appear. Store prices shown are the in-game display values. Screenshots were re-encoded to WebP with metadata removed.
- **Android TV** is represented by launcher banner artwork and by diagrams; it is labelled as artwork, not as a screenshot.
- **Diagrams** are original vector illustrations.

## Publication checks

Before publishing, every file was checked for source code, credentials, signing material, personal data, personal email addresses, local file-system paths, previous account or repository references, and embedded image metadata. None remain.

## Access

Source access for hiring or due-diligence purposes can be discussed at the owner's discretion.
